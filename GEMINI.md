# Namespace

The `namespace` MCP server connects to the user's Namespace workspace. Use it for GitHub Actions jobs that run on Namespace runners, container image builds, instance resource usage and out-of-memory events, runner profiles, and Devboxes.

- On first use, the server opens a browser login. Each login is authorized for one Namespace workspace.
- Write tools create, start, stop, and delete Devboxes and run commands in them. Confirm with the user before using them.
- Skills in this extension cover adopting Namespace runners, debugging a failed job, and working with Devboxes. Load the matching skill before starting those tasks.
- Documentation: https://namespace.so/docs
